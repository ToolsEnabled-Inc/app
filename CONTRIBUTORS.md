# Contributors

## The rule

**Contributors and maintainers are never founders.**

This file credits people who contribute code, documentation, review, translation, testing
or design to ToolsEnabled. It is a list of *contributors and
maintainers*, and it is the only place outside developers are listed.

Founder credit is separate, singular and fixed:

> ToolsEnabled was founded and created by **Joshua Pinckard**, sole founder and creator.

Contributing to this project — in any volume, for any length of time, at any level of
responsibility, including as a maintainer with merge rights — does not confer founder,
co-founder, or creator status, and does not add anyone to the founder credit. The two
categories are not a ladder. There is no contribution that promotes a contributor into a
founder, because the founder credit is a statement of who originated the project, not a
reward for effort.

This is stated here, plainly and permanently, so that nobody has to infer it and nobody has
to be told it later. Being in this file is the recognition, and it is meant as real
recognition.

## How to be listed

1. Open a pull request with your change.
2. In the same pull request, add a line to the **Contributors** list above:
   `- Name (@github-handle) — what you contributed`
3. Use whatever name you want to be credited under. A handle alone is fine.

If you would rather not be listed at all, say so in the pull request and your change will
be merged without adding you.
